# Data Model: Конституционный рефакторинг кодовой базы

**Feature**: 002-constitution-refactor | **Date**: 2026-09-04

Фича не вводит персистентных данных и не меняет доменных схем:
`AIAssessmentResult` и `CommitInfo` (фича 001) **заморожены** (FR-001).
Ниже — сущности, которыми фича оперирует: замороженный контракт
(контекст), артефакт аудита соответствия (новый) и базовый снимок
метрик (критерий «до/после»).

## 1. Публичный контракт API (заморожен — контекст)

Источник: фича 001,
[contracts/public-api.md](../001-homework-ai-detector/contracts/public-api.md).

| Элемент | Состояние в фиче 002 |
|---|---|
| Экспорт `ai_detector` (`AIDetectionService`, `AIDetectionError`, `RepoCloneError`, `MetadataExtractionError`, `CodeAggregationError`, `LLMJudgementError`, `AIAssessmentResult`, `CommitInfo`) | **Неизменен** (FR-001, SC-005) |
| Схема `AIAssessmentResult`: `status ∈ {green, yellow, red}`, `confidence ∈ [0.0, 1.0]`, `reasoning: str (min 1)`, `ai_indicators: list[str]`, `human_indicators: list[str]`; `task_compliance_score` не существует | **Неизменена** (FR-001) |

Изменения, допустимые без нарушения контракта: внутренние имена и
внутренние места (перенос констант в ClassVar, хелперы `_spawn.py`,
модульные фейки тестов) — публичная поверхность не меняется.

## 2. Артефакт аудита соответствия (новый)

Контракт формата: [contracts/audit-report.md](./contracts/audit-report.md).

- **Имя/путь**: `docs/compliance-audit.md` (сгенерирован, коммитится).
- **Генератор**: `scripts/compliance_audit.py`, запуск
  `uv run python scripts/compliance_audit.py` (stdlib-only).
- **Структура**:
  - Заголовок: дата генерации, версия Устава (1.1.0), git HEAD.
  - Раздел на каждый принцип I–VI + Technology Stack + Development
    Workflow: статус `PASS` / `DEVIACTION`, таблица доказательств
    (принцип → место → наблюдение), строка обоснования для каждого
    `DEVIACTION` (обязательна; отклонение без обоснования = ошибка
    аудита).
  - Итог: сводка статусов + число обоснованных отклонений.
- **Поведение**: полный перегенерация (замена файла, не append);
  идемпотентен — повторный запуск в неизменном состоянии кода даёт
  идентичный отчёт (кроме полей «дата/HEAD», если HEAD сместился).
- **Ключевые атрибуты**: воспроизводимость (FR-010), полнота (все
  принципы + Workflow), обоснованность отклонений (Governance).
