# Quickstart: Конституционный рефакторинг — сценарии валидации

**Feature**: 002-constitution-refactor | **Цель**: пошагово проверить, что
рефакторинг завершён: шлюзы зелёные, поведение не изменилось, аудит
соответствия подтверждает принципы Устава.

Контракты: [audit-report.md](./contracts/audit-report.md). Схемы/сущности:
[data-model.md](./data-model.md). Замороженный публичный контракт: фича 001,
[contracts/public-api.md](../001-homework-ai-detector/contracts/public-api.md).

## 1. Prerequisites

| Зависимость | Требование | Зачем |
|-------------|------------|-------|
| Python | ≥ 3.10 (окружение проекта — 3.13) | `requires-python` в pyproject |
| `uv` | последняя стабильная | управление окружением (Устав, Tech Stack) |
| `git` CLI | установлен и в PATH | интеграционные тесты на локальных репозиториях |
| `ruff` | доступен (установлен в среде) | статический шлюз (Development Workflow) |
| LLM-сервер | **не требуется** | все проверки — на заглушках (Assumption) |

Проверка: `python3 --version && uv --version && git --version && ruff --version`.

## 2. Установка

```bash
uv sync
```

## 3. Базовая линия («до» — только для сверки, опционально)

Если рефакторинг ещё не начат, зафиксированное состояние (2026-09-04):

```bash
uv run pytest                      # → 67 passed, coverage 86% (шлюз 30%)
ruff check src tests               # → 14 ошибок (5 в src + 9 в tests)
```

Это значения «база» из [spec.md](./spec.md) → «Baseline Audit»; они же —
пороги «не ниже» для итоговой валидации.

## 4. Итоговая валидация (после реализации)

Сценарии выполняются последовательно; каждый — с ожидаемым исходом.

### С1. Статический шлюз по обоим каталогам (SC-002, FR-006)

```bash
uv run ruff check src tests
```

**Ожидаемо**: `All checks passed!` (0 нарушений). Дополнительно:
`grep -n '"tests"' pyproject.toml` — каталог тестов **не** входит в
`[tool.ruff] exclude`.

### С2. Тесты и покрываемость (SC-001, SC-004, FR-008)

```bash
uv run pytest
```

**Ожидаемо**: `≥ 67 passed`, 0 провалов; в итоговой строке coverage:
`Total coverage ≥ 86%`; шлюз `--cov-fail-under=30` пройден. Отдельно
(по требованию R8): модуль `src/ai_detector/_spawn.py` в отчёте coverage —
`≥ 90%`.

### С3. Аудит соответствия Уставу (SC-003, FR-010)

```bash
uv run python scripts/compliance_audit.py
```

**Ожидаемо**: выход `0`; в `docs/compliance-audit.md`:
- по каждому из 8 разделов (принципы I–VI, Technology Stack, Development
  Workflow) — статус `PASS` либо `DEVIACTION (N)`;
- каждая строка `deviation` имеет запись в «Обоснованных отклонениях»;
- итог: 0 необоснованных отклонений.

Повторный запуск без изменений кода — идентичный отчёт (идемпотентность,
контракт §5).

### С4. Публичный контракт без изменений (SC-005, FR-001)

```bash
git status --short demo/ README.md
```

**Ожидаемо**: ни одной изменённой строки (потребителям не потребовалось ни
одной правки). Дополнительно — интеграционный смоук:

```bash
uv run pytest tests/integration/test_pipeline_smoke.py -v
```

**Ожидаемо**: полный пайплайн (клон → метаданные ∥ код → вердикт) проходит;
схема вердикта — ровно пять полей (проверяется
`test_assessment_result_has_exactly_five_fields`).

### С5. Дедупликация и структура (FR-002, FR-003, FR-004, FR-007)

```bash
# общих хелперов — по одному определению
grep -rn "def detector_temp_dirs\|def git_run\|def make_result" tests/
grep -rn "def git_stderr_tail\|def git_spawn_failure_message" src/
# изменяемых модульных глобалов в src/ — ноль (кроме классов)
grep -rn "^logger\|^_REAPERS\|= set()\|= {}" src/ai_detector/ | grep -v ClassVar
```

**Ожидаемо**: каждое имя — ровно одно определение в ожидаемом месте
(`tests/helpers.py` / `src/ai_detector/_spawn.py`); изменяемых модульных
глобалов в `src/` нет. Вложенные функции (кроме обоснованных одноразовых
замыканий) отсутствуют — это же подтверждает разделы IV/VI отчёта С3.

## 5. Критерий «всё готово»

Фича готова, когда **все** сценарии С1–С5 дают ожидаемый исход. Тогда
следующая итерация `/speckit-converge` должна завершаться `converged`
(остаточных задач нет).
